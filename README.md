# 育成リソースノート

ポケモンスリープの「アメ」と「ゆめのかけら」を記録・集計するWebアプリです。スマートフォンで日々の獲得量を記録し、期間ごとの内訳やポケモンごとの実績を確認できます。

**[アプリを開く](https://mokuhibi.github.io/pokemon-sleep-candy/)**

## 主な機能

- **ポケモンの登録・編成**：ニックネームやスキル情報を管理し、5枠の編成を設定。同じ種類の複数個体にも対応します。
- **アメの記録**：アメ拾い、ミュウ、デリバードなどの獲得数・回数を記録します。
- **ゆめのかけらの記録**：スキル、睡眠リサーチ、その他の報酬を記録します。
- **集計・分析**：日・週・月・全期間の集計、週間グラフ、月間カレンダー、獲得元別・個体別の内訳を確認できます。
- **履歴の管理**：保存した記録を確認・訂正・削除できます。
- **画像出力**：ミュウの分析やアメ種類別合計を画像として表示・保存できます。
- **バックアップ**：CSVの書き出し・復元と、旧JSONバックアップの読み込みに対応します。

## 簡単な使い方

1. **編成**タブでポケモンを登録し、5枠の編成を設定します。必要に応じてスキルや個体情報を編集します。
2. **記録**タブで日時を確認し、アメやゆめのかけらの獲得を記録します。
3. **アメ**・**ゆめのかけら**タブで期間を選び、合計や内訳を確認します。
4. 記録を直したいときは、**履歴**タブから訂正します。
5. **設定**タブから、定期的にCSVバックアップを書き出します。

1日の区切りは日本時間の朝4時、週の区切りは月曜日の朝4時です。

詳しい操作方法は、既存の **[使い方.txt](使い方.txt)** を参照してください。

## データの保存

データは利用中のブラウザのlocalStorageに保存されます。MacとiPhoneなど、端末間の自動同期はありません。

端末の移行やデータの保管にはCSVバックアップを使用してください。復元すると現在のデータが置き換わるため、必要な記録は事前にバックアップしてください。
